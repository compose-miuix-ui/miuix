# Icon System

Miuix provides a rich built-in icon system that meets the primary design needs of most applications. These icons are available in five weights: Light, Normal, Regular, Medium, and Demibold.

## Installation

The basic `miuix-ui` library includes only a small set of essential icons. The full collections live in separate artifacts, so add the one you need:

| Artifact            | Contents                        | Access               |
| ------------------- | ------------------------------- | -------------------- |
| `miuix-icons`       | Extended icons                  | `MiuixIcons.*`       |
| `miuix-glass-icons` | Glass icons                      | `MiuixIcons.Glass.*` |

```kotlin
// build.gradle.kts
commonMain.dependencies {
    implementation("top.yukonga.miuix.kmp:miuix-ui:<version>")
    // Add the extended icon library
    implementation("top.yukonga.miuix.kmp:miuix-icons:<version>")
    // Add the Glass icon library
    implementation("top.yukonga.miuix.kmp:miuix-glass-icons:<version>")
}
```

## Usage

To use Miuix icons in your project, first import them correctly:

```kotlin
import androidx.compose.foundation.layout.size
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import top.yukonga.miuix.kmp.basic.Icon
import top.yukonga.miuix.kmp.icon.MiuixIcons
import top.yukonga.miuix.kmp.icon.extended.Ok
import top.yukonga.miuix.kmp.icon.extended.Settings
```

Then, you can use the icons as follows:

```kotlin
// Use the Ok icon (defaults to Regular weight)
Icon(
    imageVector = MiuixIcons.Ok,
    contentDescription = "Ok",
    modifier = Modifier.size(24.dp)
)

// Use the Settings icon
Icon(
    imageVector = MiuixIcons.Settings,
    contentDescription = "Settings",
    modifier = Modifier.size(24.dp)
)

// Use a specific weight (e.g., Light)
Icon(
    imageVector = MiuixIcons.Light.Settings,
    contentDescription = "Settings (Light)",
    modifier = Modifier.size(24.dp)
)
```

Glass icons come from `top.yukonga.miuix.kmp.icon.glass` and are reached through `MiuixIcons.Glass`:

```kotlin
import top.yukonga.miuix.kmp.icon.glass.Close
import top.yukonga.miuix.kmp.icon.glass.Search

// Defaults to Regular weight
Icon(
    imageVector = MiuixIcons.Glass.Search,
    contentDescription = "Search",
    modifier = Modifier.size(24.dp)
)

// Use a specific weight (e.g., Light)
Icon(
    imageVector = MiuixIcons.Glass.Light.Close,
    contentDescription = "Close (Light)",
    modifier = Modifier.size(24.dp)
)
```

## Icon Weights

Miuix icons support five weights, matching the named instances of the source font `misymbol_vf.ttf`:

- `MiuixIcons.Light`: Light weight icons (wght=250)
- `MiuixIcons.Normal`: Lighter-than-regular icons (wght=305)
- `MiuixIcons.Regular`: Regular weight icons (wght=330) - Default when accessing `MiuixIcons.IconName` directly
- `MiuixIcons.Medium`: Heavier-than-regular icons (wght=430)
- `MiuixIcons.Demibold`: Demibold weight icons (wght=500)

Glass icons use the same five weights, one level deeper: `MiuixIcons.Glass` is Regular, and `MiuixIcons.Glass.Light`, `MiuixIcons.Glass.Medium` and the rest select the others.

## Glass Icons

`miuix-glass-icons` carries 176 icons extracted from `misymbol_vf.ttf`, in the same five font-native weights. Access defaults to Regular.

Two names are worth calling out:

- `Back` is the font's horizontal arrow, while `ChevronBackward` is the top bar chevron.
- Directional icons such as `ChevronBackward`, `ChevronForward` and the reply arrows mirror automatically in RTL layouts.

The icons are cached `ImageVector`s with no runtime font dependency. Tinting and press feedback belong to the consuming button.
